# KTVXL123

Repository lưu trữ các bài thực hành môn Kỹ thuật Vi xử lý (STM32).

## Danh sách buổi thực hành
- **Buoi1**:
  - `Blink_led_my`: Bài thực hành nhấp nháy LED
  - `Dieu_khien_led_74HC595`: Điều khiển LED qua IC 74HC595
  - `On_off_led`: Bật tắt LED
- **Buoi2**:
  - `TIMER_blink_led`: Tạo độ trễ bằng Timer để nhấp nháy LED
  - `TIMER_PWM`: Điều chế độ rộng xung (PWM) bằng Timer để điều khiển độ sáng LED
- **Buoi3**:
  - `On_off_led`: Bật/tắt LED qua giao tiếp UART
  - `PWM_led`: Điều khiển độ sáng LED (PWM) qua giao tiếp UART
